# BeaconWatch attendee application

This package is the supplied TypeScript starting point used throughout the
workshop. Each module preserves its existing behavior while strengthening one
operational contract with Effect.

## Test scope

`test/native-capabilities.test.ts` is the baseline characterization suite. Each
module releases an additional checkpoint test for the contract taught in that
module. Run the current module's checkpoint command before continuing.

Passing only the baseline suite confirms compatibility with the starting
behavior; it is not the cumulative workshop checkpoint.
